# ShiaoYoung · 导航

个人日常导航，收录 56 个站点，分为校园服务、学术与写作、开发与学习、AI 助手、我的工具、生活服务和休闲娱乐。支持名称、分类、关键词搜索，以及移动端双列布局。

## 本地查看

直接打开 `index.html`，或在仓库目录启动静态服务：

```sh
python3 -m http.server 8001
```

然后访问 <http://localhost:8001>。无需安装前端依赖，也无需构建；现有 GitHub Pages 工作流可直接部署。

## 维护入口

- `assets/navigation.js` 中的 `categories` 定义分类、分组和站点，每个站点的 ID 应保持唯一。`keywords` 用于补充别名和搜索词，`description` 和 `badges` 可选，显示在悬停提示中并参与搜索。
- `favoriteIds` 控制首页常用区的入口与顺序，直接引用站点 ID，无需重复填写网址。
- `assets/styles.css` 管理主题与响应式布局。导航按钮统一为 172 × 50px，按行居中，按钮文字居中；600px 及以下保持双列，窄屏统一缩小宽度。
- 常用区之后直接展示各分类内容；使用原版的字号、半透明卡片底色、8px 磨砂模糊和卡片悬停阴影。背景图额外应用 2px 轻微模糊。
- 页面按名称、分类、分组、说明和关键词即时筛选；多个词以空格分隔时需同时匹配。搜索结果不重复显示常用区入口，按 Escape 或点击清空即可恢复。
