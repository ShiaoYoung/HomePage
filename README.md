# ShiaoYoung · 导航

个人日常导航，收录 56 个站点，分为校园服务、学术与写作、开发与学习、AI 助手、我的工具、生活服务和休闲娱乐。支持名称、分类、关键词搜索，以及移动端双列布局。

## 本地查看

直接打开 `index.html`，或在仓库目录启动静态服务：

```sh
python3 -m http.server 8001
```

然后访问 <http://localhost:8001>。无需安装前端依赖，也无需构建；现有 GitHub Pages 工作流可直接部署。

## GitHub Pages 部署

推送到 `main` 后会自动部署，也可以在 Actions 中选择「Deploy static content to Pages」→「Run workflow」启动新运行。

部署产物按运行编号和重试次数命名，上传与部署步骤引用同一个名称，避免重跑时遇到 `Multiple artifacts named "github-pages"`。修改工作流后应推送新提交或从最新 `main` 启动运行，直接重跑旧提交的失败任务不会应用新的工作流配置。

## 维护入口

- 页面右上角可切换森林绿与山大红主题，山大红主色为 `rgb(156, 12, 19)`（`#9c0c13`），标题为黑色，按钮默认淡红底、红色描边，悬停时红底白字。背景沿用森林纹理，通过 CSS 明度混合转为山大红并轻微模糊，标题保持半透明磨砂。首次打开默认森林绿，选择保存在当前浏览器的 `shiaoyoung.homepage.theme.v1`；存储不可用时仍可在本次访问中切换。

- `assets/navigation.js` 中的 `categories` 定义分类、分组和站点，每个站点的 ID 应保持唯一。`keywords` 用于补充别名和搜索词，`description` 和 `badges` 可选，显示在悬停提示中并参与搜索。
- 点击常用区右侧的「设置」，可勾选站点、上移/下移排序或移除，点击「保存」后立即生效；取消或按 Escape 不保存草稿。「恢复默认」也需要点击保存才生效，允许清空所有常用入口。
- 配置使用 `localStorage` 保存在当前浏览器，键为 `shiaoyoung.homepage.favorites.v1`，刷新后保留。不同浏览器、设备或访问地址的配置彼此独立；无法写入时会在设置窗口提示，保留草稿以便重试。
- `defaultFavoriteIds` 定义没有本地配置时的默认入口与顺序，也用于「恢复默认」，直接引用站点 ID，无需重复填写网址。
- `assets/styles.css` 管理主题与响应式布局。导航按钮统一为 172 × 50px，按行居中，按钮文字居中；600px 及以下保持双列，窄屏统一缩小宽度。
- 常用区之后直接展示各分类内容；使用原版的字号、半透明卡片底色、8px 磨砂模糊和卡片悬停阴影。背景图额外应用 2px 轻微模糊。
- 标题区域使用原版的半透明背景、10px 磨砂模糊、描边和阴影。
- 背景与内容使用明确的绘制层级，磨砂效果同时声明 Safari 前缀。旧版浏览器缺少原生 `dialog` 时使用带遮罩、焦点约束和 Escape 关闭的后备弹窗；窗口高度同时提供 `vh` 后备值。
- CSS 和 JavaScript 地址携带资源版本参数；发布资源更新时同步更新 `index.html` 中的版本值，以避免浏览器沿用旧资源。
- 页面按名称、分类、分组、说明和关键词即时筛选；多个词以空格分隔时需同时匹配。搜索结果不重复显示常用区入口，按 Escape 或点击清空即可恢复。

## 验收记录

已用 Chromium 检查 375px、390px、768px 和 1440px 布局、原有网址保留、搜索与清空、键盘焦点，以及直接打开本地文件时的搜索功能。

常用设置已验证勾选、增删排序、取消与 Escape、保存后刷新和新页面读取、恢复默认、空列表，以及本地数据损坏或存储不可用时的处理。

Safari 兼容调整已用 Playwright WebKit 在独立站点来源下验证：背景与标题磨砂显示、设置弹窗、勾选排序、本地保存与刷新恢复；缺少原生 dialog 的后备路径也已单独验证。该检查不替代具体 Safari 版本的实机验证。
